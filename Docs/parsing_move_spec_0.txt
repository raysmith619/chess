Our plan is to recognize (parse)
parts of the chess move
specification

We'll use a well known
pattern matching term / language
 regular expression
It's been around much longer
than languages such as Java or Python

Different programming languages
provide regular expression
matching support in different ways.

Example: Chess game result

1-0			white wins (black loses)
0-1			white loses (black wins)
1/2-1/2	  	draw

regular expression pattern
1-0|0-1|1/2-1/2		
			matches - Any of the Three "1-0" or "0-1"
			or "1/2-1/2"
	Note that in reading
	we have	long used
	the '"' character to
	show a special interpretation

Regular expression
Pattern Matching Special
characters
[DON'T NEED TO REMEMBER THESE]
| - pattern1 or pattern2
^ - matches beginning of string
$ - matches end of string
. - matches any  charcter
\ - makes following special
    character into a regular matchable
	example: \. matches a dot
	Note: \ makes some regular characters
	into special characters
	examples:
		\s - matches "white space" character
		 includes spaces, tabs, newlines,
		 carriage returns, form feeds,
		 and vertical tabs
			Confession: I had to look up
				all these after space and tab

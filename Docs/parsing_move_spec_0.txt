					 ab|cd|efg  - matches "ab" or "cd" or "efg"
								Note that in reading we have
								long used the '"' character
								to indicate a special interpretation

Pattern Matching Special characters (DON'T NEED TO
									REMEMBER THESE)
| - pattern1 or pattern2
^ - matches beginning of string
$ - matches end of string
. - matches any  charcter
\ - makes special character regular
	example: \. matches a dot
	Note: \ makes some regular characters
	into special characters
	examples:
		\s - matches "white space" characters
			 includes spaces, tabs, newlines,
			 carriage returns, form feeds,
			 and vertical tabs
				Confession: I had to look up
					all these after space and tab

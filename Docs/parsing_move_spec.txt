import re	# Makes re matching available

game_res_match = re.match(
			r"^(.*)(1-0|0-1|1/2-1/2)$",
			rem_str)

if game_res_match:
	rem_str, game_res = game_res_match.groups()

NOTES:
1. "import re" imports re module
providing regular expression support.

2. re.match() looks for
pattern ^(.*)(1-0|0-1|1/2-1/2)$
in string rem_str.  If pattern
matches (is found) re.match
returns a "match object".
If not found, re.match returns None.

3. <match object>.groups() returns
a tupple of captures in the match.
The capture groups, numbered from 1 on the
left, are created by counting
left parentheses.
  group 1: (.*),
		everything to left of
		game result,

  group 2: (1-0|0-1|1/2-1/2),
			game result

Rest of the patterns follow.
The are processed in order.

We take the move specification
string apart bit by bit.

Programming code is
ommitted to concentrate 
on the patterns

Two check/checkmate patterns:

	^(.*)(\+|#)$
	
	^(.*)([+#])$

The pattern "[" followed by one or
			more characters
			ending with "]"
matches any one of the included
characters


	^(.*?)(0-0|0-0-0)$			# king and queen castle
								# NOTE the .*? which is # a lazy(non-greedy)
								# instead of greedy grabbing
	
	^(.*)(=[QRBN])$				# Promotion
	^(.*)([a-h][1-8])$   		# destination square
	^(.*)([x:])$					# capture
	
	^([KQRBN])(.*)$				# Piece  could be
								# a P for pawn
								#  Match indicates regular piece
								#  No match indicates
								# pawn
	^([a-h])(.*)$				# source file
								# disambigate
								
	^([1-8])(.*)$				# source rank
								# disambigate
